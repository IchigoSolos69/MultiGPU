# Additional general clouds and research allocations

Official-source research checked **24 October 2026**. This adds candidates beyond the app's original 13 entries. These are published training capabilities and offers, **not qualified MultiGPU connectors**. Availability, quota, permitted use, payment requirements, credit eligibility and price must be rechecked in the user's own account before execution.

## Counting and classification

This file identifies **14 commercial cloud vendors**, plus **six overlapping research/allocation routes**. Google Cloud is an additional product family for the existing Google/Colab relationship, so it is **not another unique vendor** if Colab Enterprise is already counted under Google. Amazon SageMaker AI, EC2 and Studio Lab are one AWS vendor; Tencent Cloud Studio and GPU Cloud are one Tencent vendor. ACCESS, NAIRR and CloudBank can lead to the same machine or commercial cloud award and must not be counted as independent pools of guaranteed free GPUs.

None of the 14 vendors below establishes a generally available, unlimited, recurring free GPU entitlement for every new user. Tencent Cloud Studio and Huawei CodeLab have regional, conditional free resource evidence; AWS Studio Lab is closed to new customers. Research allocations are genuine no-cost opportunities for eligible, approved projects rather than public signup allowances.

### AWS Studio Lab availability correction

The current operational documentation says **Studio Lab no longer accepts new customers**. Existing customers may continue using it, but AWS is not planning new features. Some pricing/marketing pages still call it a free way to train models without prominently explaining signup closure. It belongs in an existing-account-only or closed-to-new-users section, not the app's new-user free GPU recommendations. [Current Studio Lab documentation](https://docs.aws.amazon.com/sagemaker/latest/dg/studio-lab.html).

### Prices, promotions and integration confidence

Rates above are intentionally linked rather than normalized into a misleading universal GPU-hour price. A number can refer to a whole server, one GPU within a mandatory eight-GPU server, an interruptible instance, or a multi-year commitment. Provisioning SDK/API availability is a promising integration path; **the app still needs launch, progress, cancellation, allowance exhaustion, checkpoint and local export tests** for each new connector. No accounts were created or billed during this research.

### Paused program: NVIDIA Academic Grant Program

NVIDIA's current U.S. page prominently says it is **not accepting new applications**, although legacy call cards and an Apply Now link remain below. The page describes competitive university-faculty eligibility and cloud/hardware awards, including training GPU hours. Keep it as a paused research opportunity until NVIDIA explicitly reopens applications; do not promote it as an active public free GPU signup. [Official program and current notice](https://www.nvidia.com/en-us/industries/higher-education-research/academic-grant-program/).

## Recommended additions for MultiGPU

1. Expand the directory with the 14 commercial vendors, grouped by vendor and tagged **paid**, **conditional credit**, **regional promotional compute**, or **existing-account-only** as applicable. Preserve Google vendor deduplication.
2. Add a separate **Research allocations** category for ACCESS/NAIRR/EuroHPC/TRC, linking host resources without double-counting them as independent free pools.
3. Prioritize generic authorized **SSH/Slurm**, VM lifecycle and managed-training adapters. An integration path is an engineering assessment, not a supported-connector claim.
4. Keep requested devices and actual allocation distinct: TPU, Trainium, Gaudi and AMD ROCm training need explicit recipe/runtime support. Do not label every accelerator CUDA-compatible.
5. Before using promotions, observe expiry, eligible SKU, quota, region, storage/transfer costs and enforceable account controls. A generic credit headline or local stop timer cannot guarantee a zero provider bill.

Not included as verified GPU entries: CloudSigma (a current official training-GPU product page was not successfully established in this pass), inference-only APIs, pricing aggregators, speculative future hardware and expired promotional blog posts. Absence from this file does not establish that a vendor has no qualifying product.
